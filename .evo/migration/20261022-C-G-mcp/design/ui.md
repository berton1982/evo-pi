## 交互态

| 态 | 触发 | 表现 |
|---|---|---|
| loading | 首次挂载 / 刷新 | 列表显示 3 行骨架，开关与「测试」禁用，工具栏骨架按钮 |
| empty | 两份配置都为空 | 空态卡片：路径 + 可抄 JSON + 就地添加表单 |
| error | 任一份配置文件读失败 | 顶部错误条（含文件路径与行号）+ 重试；另一份可用时继续展示 |
| running | 点「测试」 | 状态行显示 `● 测试中`，40s 超时后转失败并给出日志尾部 |
| success | 测试返回 tools | 状态行 `● 成功 <ms>`，工具清单可折叠（>5 个默认折叠） |
| filtered | 项目路径未提供 | 只渲染用户级分组，并在工具栏提示「项目级需传入 cwd」 |
