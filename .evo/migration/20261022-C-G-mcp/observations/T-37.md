# T-37 移除服务器 — 观察

## 看到什么

pi-web `components/McpConfig.tsx:631` 的 `removeServer` 是 `useCallback`，`DELETE /api/mcp` 带 scope+name；
入口在 `:817`（列表层 `onRemove` 透传）、`:1161`（详情区渲染按钮）；`:911` 的 prop 是可选 `onRemove?`。
按钮自身没有二次确认，删除后选中项由 `:640` 附近置空。

## 差在哪

我们 C5 最初只做了「测试」一个详情动作：没有 `DELETE /api/mcp` handler、没有 `remove-server` 用例、
详情区没有「移除」按钮；行选中项在删除后不会清空（pi-web 在 `:640` 附近处理）。

## 决定

补齐四层：core `createRemoveServer` → infrastructure `removeServer`（幂等、保留空对象）→ `DELETE /api/mcp`
→ 详情「移除」按钮；删除的正是选中项时 `select(null)`。破坏性动作不与「测试连接」相邻（手滑代价不同）。
