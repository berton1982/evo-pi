# 质量与测试策略 — C-H「设置 · 技能」

> 给实施的人看：写的时候就按这里的数字收，而不是等 review 再说"太大了"。
> 给测试的人看：§2 就是排期表——每层写在哪、挡什么错、不挡什么。
> 机器判据：D9（预算必须有数字、不得出现模糊词）· D18（最佳实践要落到元素）。

## 1. 质量预算

| 项 | 上限 | 怎么量 | 触线时的第一反应 |
|---|---|---|---|
| 单文件行数 | 400（`design/` 与 `ui/` 目录）；200（presenter 组件） | `wc -l` | 先把纯函数抽出去，而不是先拆组件 |
| 函数圈复杂度 | 12 | review 时数分支 | 把"错误分类"抽成映射表 |
| 组件 props | 6 | 数 `interface Props` 字段 | 超过说明职责没分干净，先拆容器 |
| 单组件 JSX 嵌套 | 4 层 | 看缩进 | 抽子组件或抽 `renderX()` 函数 |
| `useEffect` | 每组件 2 个 | 数调用 | 第三个多半说明这段逻辑该在事件回调里做 |
| 行内样式 | 0 | `grep style={{` | 用 token 类名（`arch/frontend.md` 约定） |
| 新增 token | 0 | 对比 `design-system.md` | 需要新 token 就是契约变更（提 CHG） |

## 2. 测试策略（五层）

| 层 | 写在哪 | 挡什么错 | 不挡什么 | 本能力具体条目 |
|---|---|---|---|---|
| L1 域函数单测 | `packages/core/src/skills/domain/*.test.ts` | 排序、分组、锚点解析、回滚计算的纯逻辑错 | 界面、请求时序 | `orderSkillsByDormancy`、`resolveSkillLink`、`applySkillToggleResults` 的边界（空数组、重复 key、失败项缺 id） |
| L2 用例单测 | `packages/core/src/skills/use-cases/*.test.ts`（端口用内存假实现） | 编排错、错误码映射错、幂等与取消语义 | 真实 IO | `D-B-01/04/05` 的成功、失败、部分失败三种路径 |
| L3 组件测试 | `packages/web/src/capabilities/skills/ui/*.test.tsx` | props 契约、三态渲染、a11y 角色、回调参数 | 真实网络与持久化 | `C-02` 的错误码可见、`C-03` 键盘安装、`C-01` 空态 |
| L4 端到端 | `e2e/skills/*.spec.ts`（`harness/` 的 18 条脚本） | 跨层拼接、真实路由与 SSE、刷持久化 | 视觉细节 | `B-001`…`B-018` 逐条对应 |
| L5 手工 | 本文件 §3 | 观感、文案、真实设备的键盘与读屏 | — | L6 人类验收前的自检 |

**反向原则**：L1 能挡的错不要写进 L4——e2e 慢且脆；L4 才能挡的错（持久化、路由）不要指望 L1。

## 3. 三态与无障碍清单（手工验收对照）

| 场景 | loading | 空态 | 错误态 |
|---|---|---|---|
| 技能列表 | 骨架屏 ≥3 行 | "这个项目还没有技能" + 指向安装按钮 | 错误码 + 重试按钮 |
| 详情正文 | 面板内骨架 | "这个技能没有 SKILL.md" | 错误码 + 重试 + 关闭 |
| 市场搜索 | 搜索框 `aria-busy` | "没有匹配的技能" | 错误码 + 保留输入 |

键盘路径：`Tab` 可达列表项 → `Enter` 打开详情 → `Esc` 关闭详情 → 焦点回到原列表项（不能丢焦点）。
读屏：列表项 `role="option"`、开关 `role="switch"` + `aria-checked`、错误提示 `role="alert"`、空态 `role="status"`。

## 4. 性能预算

| 指标 | 目标 | 怎么测 |
|---|---|---|
| 首屏到可交互 | < 2000ms（本地 30041） | `harness/` 快照里的 `performance.timing` |
| 开关反馈延迟 | < 100ms（乐观更新，不等请求） | 手工 + L3 断言"点击后立即 onChange 生效" |
| 24 个技能批量开关 | 1 次请求 | L2 断言 `setEnabledBatch` 调用次数 = 1 |
| 列表重渲染 | 单条变化只重渲染该条 | React DevTools Profiler 手工抽查 |
