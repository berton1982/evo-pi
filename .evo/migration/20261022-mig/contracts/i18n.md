# i18n 契约 — 键命名空间与语言包

> 版本：v0.2（CHG-003：登记 `i18n.` 通用文案命名空间及其归并规则）

> **为什么冻结**：迁移期间两个前端并存，键名一旦漂移，同一句话会出现两种译法；更糟的是缺键时退回英文而没人发现。
> **核对**：C6 的差异报表会逐键比对 `en.ts` 与 evo-pi 语言包的键集合；缺键/多键都必须分类（不是"差不多就行"）。

## 1. 语言包清单（以 pi-web 为准）

| 文件 | locale | 键数 |
|---|---|---|
| `lib/i18n/messages/en.ts` | `en` | 1477 |
| `lib/i18n/messages/zh-CN.ts` | `zh-CN` | 与 en 同集合 |
| `lib/i18n/messages/zh-TW.ts` | `zh-TW` | 与 en 同集合 |

存储键：`localStorage["pi-locale"]`（`hooks/useI18n.tsx:8`）。**迁移后键名不变**，否则用户语言偏好会丢。

## 3. 键规则

1. **键名不改**：迁移是搬家不是改名；要改名必须走 `CHG-` 并同时改三个语言包。
2. **不许拼字符串**：`t(\`chat.${k}\`)` 这类动态键必须在文件里列出所有可能值，否则缺键检测失效。
3. **插值用 `{name}`**，不用 `%s` / `${}`；参数名在三个语言包里必须一致。
4. **新键先英文**：新增文案先进 `en.ts`，其余语言包允许暂缺（缺键检测会列出来，不许复制英文占位）。
5. **页面标题走 `title.`**，不用硬编码字符串（`<title>` 与文档标题一致）。
