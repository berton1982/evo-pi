## 交互态

| 态 | 触发 | 表现 |
|---|---|---|
| 加载 | 首次进入 | 列表区骨架 + 标题不动（不整页转圈） |
| 空 | 两份配置都没有 server | 上图空态，含路径、示例、就地添加表单 |
| 失败 | 配置读不出来 / 403 | 红色提示条写原因与下一步，列表保留上次已知数据 |
| 成功 | 测试连接通过 | 状态点变绿 + 「N 个工具」+ 日志可展开 |
