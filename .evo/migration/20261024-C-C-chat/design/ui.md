# UI 原型 — C-C 会话面

## 1. 主屏（工具栏 / 列表 / 详情 / 状态）

```text
┌──────────────────────────────────────────────┬──────────────┐
│ 顶栏L：[信任项目][完整历史][生成标题][分支][系统][工具]  顶栏R：[会话信息][文件面板] │  文件面板 │
├──────────────────────────────────────────────┤  ┌────────┐  │
│ ┌──────────────────────────────────────────┐ │  │ 文件树 │  │
│ │ 列表（role=log, aria-live=polite）        │ │  │        │  │
│ │  用户气泡                                │ │  └────────┘  │
│ │  助手消息：思考(可展开) / 文本 / 工具调用 │ │              │
│ │  详情：diff 左删右增两栏                 │ │              │
│ └──────────────────────────────────────────┘ │              │
├──────────────────────────────────────────────┤              │
│ 条件行：状态「正在推理…」或「已完成 · 3 步」  │              │
│ 队列：引导 · 先看下 src 再答（accent 边）     │              │
│       追加 · 顺便写个测试（dim 边）  ↺ 撤回   │              │
│ 表单：[📎] 草稿…            [▲ 引导][▼ 追加] │              │
│       更多控件 ▾（折叠态）  ┆ 模型 · 推理 · 预设 · 压缩       │
└──────────────────────────────────────────────┴──────────────┘
```

**区顶栏分工（已查证 `AppShell.tsx`）**：主区顶栏左侧 = 信任项目（未信任时）/ 完整历史（`:1555`）/ 生成标题（`:1624`）/ 分支（`BranchNavigator`）/ 系统提示词（`:1770`）/ 工具（`:1807`）；右侧 = 会话信息按钮（`:1860`，点开面板）。**「新建会话」在左侧区顶部**（`sidebar-header.tsx:52`），主区顶栏不放新建——我们当前实现把新建放在主区顶栏，属偏离，C5 要改。

**输入区工具条形态（已查证 `ChatInput.tsx`）**：主行只有 **附件 / 发送**（运行中换成 **引导 ▲ / 追加 ▼**）；模型、推理级别、工具预设、压缩（进行中变"停止压缩"）、声音、输入历史、停止 agent **全部收进「更多控件」折叠面板**（`ChatInput.tsx:2471`、`:2508`、`:2736`、`:2754`）。我上一版把它们画成平铺，是错的。

## 1.1 运行中（agent 正在推理）

```text
┌──────────────────────────────────────────────┐
│ 状态：正在推理…（可排队，不打断当前轮次）      │
│ 状态行：1 条引导 · 0 条追加     ↺ 撤回(列表)   │
│ 表单：草稿…                          ▲ 引导  │
│                                      ▼ 追加  │
│ 更多控件 ▾ · 停止 agent（红）                  │
└──────────────────────────────────────────────┘
```

语义（`chat.steerHint` 原文）：**引导 = 当前响应及其工具调用结束后投递；追加 = 作为下一轮；停止会打断它们。**

## 2. 空态（空态 / 表单）

```text
┌──────────────────────────────────────────────┐
│ 空态：还没有消息                              │
│  状态：未开始 · 列表为空                      │
│  ┌────────────────────────────────────────┐  │
│  │ 表单：[模型▾] 问点什么…          发送   │  │
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

## 3. 失败态（状态 / 列表）

```text
┌──────────────────────────────────────────────┐
│ 状态：⚠ 这一条消息渲染失败（其余不受影响）    │
│   原因：<原始错误文本>                        │
│   [重试这一条]                                │
├──────────────────────────────────────────────┤
│ 状态：历史加载失败 [重试] 已加载内容保持       │
└──────────────────────────────────────────────┘
```

## 交互态

| 态 | 触发 | 表现 |
|---|---|---|
| 流式中 | `message_start` | 底部出现光标块，自动贴底（用户上滚则停） |
| 已中止 | Esc / 停止 | 该轮标"已中止"，消息保留 |
| 思考加载中 | 展开思考块 | 块内显示加载占位，不阻塞其他块 |
| 错误 | 渲染/请求失败 | 只降级该条，列表其余正常 |
| 复制成功 | 点复制 | 按钮短暂显示"已复制" |
| 运行中排队引导 | 运行中点 ▲ 引导 / `Alt+Enter` | 队列新增一条 accent 边行，当前轮次不中断 |
| 运行中排队追加 | 运行中点 ▼ 追加 | 队列新增 dim 边行，本轮结束后作为新一轮发送 |
| 撤回队列 | 点 ↺ 撤回 | 全部排队消息回填输入框，队列清空 |
| 正在压缩 | 点「压缩上下文」 | 按钮变「停止压缩」，行内显示压缩进度 |
| 更多控件展开 | 点「更多控件」 | 展开模型/推理级别/工具预设/压缩/声音/输入历史 |
