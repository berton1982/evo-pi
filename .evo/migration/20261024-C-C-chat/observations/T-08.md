# T-08 观察 — diff 渲染（D-U-14 / C-05）

## 看到什么

| 位置 | 事实 |
|---|---|
| `ref_projects/pi-web/lib/patch.ts:1-10` | 共享模型：`SplitDiffCellType = context/removed/added/empty`、`SplitDiffCell { lineNo, text, type }`——**空单元格是一等公民**（左右对齐靠它） |
| `ref_projects/pi-web/lib/apply-patch.ts:88-140` | `createRowSink`：pendingRemoved/pendingAdded 成对 flush，`Math.max` 补齐较短一侧，`finish()` 丢掉没有行体的文件 |
| `MessageView.tsx:1570-1610` | 两条数据源（V4A 入参 / `details.preview` 带行号的 `+12 text`）都转成 `SplitDiffFile[]`，**复用同一个分栏视图** |
| `MessageView.tsx:1593` | 头部列出补丁命中的所有文件 |

## 差在哪

- 我们已有 V4A 解析（`patch-diff.ts`，T-05 已过）但**没有 preview 解析**（`+12 text` 形态）也没有分栏组件。
- 差异点：pi-web 的 `lineNo` 来自 preview 行首数字；我们 V4A 侧一律 `null`——两种来源要能共存（同一组件渲染），所以 `DiffCell.lineNo` 允许 `null`。

## 决定

1. 补 `parsePreviewDiff(preview)`（`+12 text` / `-3 text` / ` 7 text`）进 `packages/core/src/chat/domain/patch-diff.ts`，与 `splitPatch` 输出同一 `DiffRow[]`。
2. 分栏组件 `diff/split-diff.tsx`：左右两列固定宽度百分比、`empty` 单元格留底色、行号列宽固定（否则滚动时抖动）。
3. 不做语法高亮（沿现有依赖，CHARTER 不做清单第 3 条）。
