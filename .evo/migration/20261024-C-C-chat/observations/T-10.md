# T-10 观察 — 通知与容错（D-U-07 / C-01）

## 看到什么

| 位置 | 事实 |
|---|---|
| `ref_projects/pi-web/components/ChatWindow.tsx:1072` | `<NoticeShelf notices={notices} floating onPauseChange={…} />` 浮在列表之上 |
| `ChatWindow.tsx:1550-1560` | 空数组直接返回 `null`（不占高度）；容器右对齐、每条 toas​t 右边缘对齐、宽度向左生长；`floating` 时不加下边距 |
| `ChatWindow.tsx:1550` | `onPauseChange` 让**悬停暂停**自动消失（读屏与手慢用户的关键） |

## 差在哪

- 我们有 `ST-03 noticeQueue` 的设计但没有渲染与暂停逻辑。
- pi-web 的 notice 是"浮层"；我们上一版设计成列表底部的一行——位置不同会让消息滚动时被遮挡。

## 决定

1. `notice-shelf.tsx`（D-U-07）绝对定位在列表容器右上，`pointer-events-auto` 只给卡片本身。
2. 队列上限 3 条、先入先出；鼠标进入卡片调 `pause(id)`，离开 `resume(id)`。
3. 无 notice 时返回 `null`（不占空间），与 pi-web 一致。
