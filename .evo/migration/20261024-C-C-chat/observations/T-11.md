# T-11 观察 — 扩展 UI 边界（D-U-07 / D-B-06）

## 看到什么

| 位置 | 事实 |
|---|---|
| `ref_projects/pi-web/components/ChatWindow.tsx:1080` | 扩展 UI 用 `<ExtensionCustomPanel request={extensionCustomUi} waitingCount onInput />` 渲染，插在消息列表与输入框之间 |
| `ChatWindow.tsx:2074` | 面板本体 47 行起，接收 `BlockingExtensionUiRequest` |

## 差在哪

- 本能力**砍单**这段（`CHAT​ER.md` §3 第 1 条、`cut-list.md` 1 条、CHG-004）。
- 但不能"看不见"：pi-web 在收到 `extension_ui_request` 时会阻塞式弹面板；我们只显示一条提示，否则用户会以为 agent 卡死。

## 决定

1. `D-B-06` 用例 `noteExtensionUiRequest()`：把请求记进 `ST-03` 队列，文案"扩展 UI 暂未支持（本能力未迁）"。
2. 不渲染面板、不回传 `extension_ui_response`——这是 C-A 的协议责任，不在这里假装实现。
3. 提示只出一次（按 `request.id` 去重），避免每秒刷屏。
