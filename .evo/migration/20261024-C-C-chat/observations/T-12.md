# T-12 观察 — e2e 基线（D-U-05）

## 看到什么

| 位置 | 事实 |
|---|---|
| `ref_projects/pi-web/components/ChatWindow.tsx:1089` | 列表容器没有 `data-testid`，pi-web 的 e2e 用结构选择器 |
| `packages/web/src/features/mcp/mcp-panel.tsx` | 我们自己的先例：容器级 `data-testid`（`mcp-server-list` 等），e2e 全部按 testid 取 |
| `packages/web/ARCHITECTURE.md` §8 | 壳的挂点用 `data-component` / `data-action` |

## 差在哪

- 我们没有 chat 的 e2e 目录；pi-web 那边也没法抄选择器（它不用 testid）。

## 决定

1. 本能力统一加 `data-testid`：`chat-scroll`、`chat-empty`、`chat-message-user|assistant`、`chat-retry`、`composer-input`、`composer-send`、`composer-steer`、`composer-followup`、`composer-more`、`composer-queue`、`chat-notice`。
2. `e2e/chat/s-001…` 每条断言只按 testid + 可及名，不按 className（CSS 改动不该让 e2e 红）。
3. 多语言断言用双语正则 `/(Send|发送)/`（Playwright 默认 en-US，已被 MCP 试点踩过）。
