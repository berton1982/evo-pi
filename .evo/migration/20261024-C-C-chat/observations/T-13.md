# T-13 观察：共享类型与常量

## 看到什么
- 列宽与内边距是常量：`ref_projects/pi-web/components/ChatWindow.tsx:96`（`CHAT_COLUMN_PADDING = 16`），实际用在 `:1068` 的 `padding: 0 ${CHAT_COLUMN_PADDING}px`。
- 分页大小从模块导入，不在组件里写死：`ref_projects/pi-web/components/ChatWindow.tsx:45`（`VISIBLE_PAGE_SIZE` 来自 `lib/chat-lazy-load.ts`）。
- 应用更新检查是**模块级单飞缓存**，不是每个组件各发一次：`ref_projects/pi-web/components/ChatWindow.tsx:102-113`（`appUpdateCheck ??= fetch(...)`）。

## 差在哪
我原来的做法是把长度/分页/缓存都塞进组件 state；`ChatWindow` 的写法把「不随会话变化的常量」放到模块顶，把「只在需要时算一次」用 `??=` 表达。移植时若写成 `useState(() => fetch(...))`，每挂载一次就打一次 `/api/app-update`。

## 决定
常量与单飞缓存移到 `packages/web/src/features/chat/domain/chat-constants.ts`（纯值 + 纯函数），组件只 import；`useEffect` 里不做网络调用。
