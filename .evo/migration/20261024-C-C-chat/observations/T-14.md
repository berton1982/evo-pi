# T-14 观察：更新可用横幅

## 看到什么
- 更新检查结果先落模块级变量再进 state：`ref_projects/pi-web/components/ChatWindow.tsx:102-103`（`appUpdateCheck` / `appUpdateFound`）、`:130`（`useState(() => appUpdateFound)`）。
- 已经找到更新就不再重复检查：`ref_projects/pi-web/components/ChatWindow.tsx:133`（`if (appUpdateFound) return`）。
- 请求本身在 `ref_projects/pi-web/components/ChatWindow.tsx:106`（`fetch("/api/app-update")`）。

## 差在哪
我原设计把「有没有更新」当成会话态（跟着 entryId 走），但它是**应用级、与哪个会话无关**的信息；放在会话 store 里会导致每次切会话都重置成「未知」。

## 决定
更新态独立成 `useAppUpdate`（应用级，不带 sessionId），横幅只读它；`ChatWindow` 里的模块级缓存语义用「同一进程内只请求一次」保留。
