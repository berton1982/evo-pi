# T-15 观察：工具块视图与通知条

## 看到什么
- 工具块把「调用」与「结果」分开传：`ref_projects/pi-web/components/MessageView.tsx:1176`；守卫在 `:274-330`（`haveSameRelevantToolResults`，避免整棵树重渲染）。
- 通知条右对齐、悬停暂停计时：`ref_projects/pi-web/components/ChatWindow.tsx:1550`（`NoticeShelf`，`alignItems: "flex-end"`，注释写明「每个 toast 右边缘对齐、向左延展」），浮动态在 `:1072`（`notices={notices} floating`）。
- 空列表直接不渲染：`ref_projects/pi-web/components/ChatWindow.tsx:1551`（`if (notices.length === 0) return null`）。

## 差在哪
我原设计把 `notice` 当成消息数组里的一个元素，而 pi-web 是**覆盖层**（floating），不占消息流位置；另外暂停逻辑（`onPauseChange`）我漏了——鼠标停在通知上会暂停自动消失。

## 决定
`features/chat/notice-shelf.tsx` 独立组件，`alignItems: flex-end` + `onMouseEnter/Leave` 暂停；不进 `ST-01` 消息 store。
