# T-19 观察 — 消息详情与重试条（C-03 / C-04 / ST-02 / ST-03）

## 看到什么

| 位置 | 事实 |
|---|---|
| `MessageView.tsx:334` | 用户消息视图接收 `onEditContent` / `onFork` / `isEditing`（可编辑、可分支） |
| `MessageView.tsx:644` | assistant 视图接收整条消息 + 展示选项 |
| `MessageView.tsx:274-330` | `haveSameRelevantToolResults`：相关工具结果没变就不重渲染 |
| `MessageView.tsx:242-252` | `formatTime` 无时间返回 `null`（不留空占位） |
| `MessageView.tsx:162` | `loadThinkingContent(sessionId, entryId, blockIndex)`：thinking 正文按需拉取 |

## 差在哪

- 我们 `message-item.tsx` 只有展示 + 重试按钮；thinking 正文按需加载、时间戳、复制都还没有。
- 分支与编辑属 C-B（`CHARTER.md` §3 第 2 条），不迁。

## 决定

1. `use-message-actions.ts`（H-04）提供 `copy(id)` / `retry(id)` / `timestamp(id)`，由 `ST-02` 存"正在复制/正在重试"的瞬时状态。
2. thinking 正文按需加载放 `use-message-model.ts`（D-U-09），键用 `entryId + blockIndex`（与 pi-web 同键，便于以后对齐缓存）。
3. 时间戳缺失时不渲染节点（不写 `—`）。
