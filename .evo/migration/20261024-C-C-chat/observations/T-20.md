## 决定

1. `composer-queue.tsx`（C-07）：队列行 + `chat.queued · n` + ↺ 撤回；撤回把文本回填 `ST-02` 的草稿。

3. 动画不做（仓库没有 keyframes 约定），用 `data-state` + CSS transition 代替。
