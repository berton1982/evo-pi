# Triage 标签

Skills 使用五个标准的 triage 角色。本文件把每个角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库的标签 | 含义 |
| -------------------------- | ------------ | ---- |
| `needs-triage`             | `needs-triage` | 维护者需要评估此 issue |
| `needs-info`               | `needs-info` | 等待报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent` | 规格完整，可由 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix` | 不会处理 |

当某个 skill 提及某个角色（例如 "apply the AFK-ready triage label"）时，使用表中对应的标签字符串。

修改右侧一列以匹配实际使用的词汇。
